### 研究方向

- **后训练数据质量与评测**：以模型能力需求定义数据质量，通过评测反馈指导数据建设，将数据优化与训练迭代结合。关注质量标准的有效性，以及数据改进对模型能力的实际价值。

- **多模态理解与语义一致性**：围绕跨模态语义一致性，将复杂理解任务转化为可验证的判断，通过分层理解、多模型协同与证据交叉验证，提高评估的可靠性和可解释性。

- **强化学习与可验证奖励**：探索质量评估与模型优化的结合，将可验证的评价信号转化为学习反馈。关注奖励设计与真实目标的一致性，以及多个优化目标之间的平衡。

- **Agent 与 Long Horizon 数据质量**：将任务、环境与评价机制作为整体进行分析，通过独立验证检验过程证据与最终评价的一致性，探索长程交互数据的质量评估方法。
