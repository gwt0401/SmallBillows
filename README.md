### 研究方向

- **后训练数据质量**：把上下文缺失、指令遗漏和事实错误等问题变成可检查的规则，并用人工标注集校准 LLM-as-Judge。
- **视频理解与 Caption**：把视频描述拆成可核验的断言，在具体片段和画面细节中找证据，再修正 Caption 中的错误。
- **强化学习**：把断言级质量反馈用于 Caption 训练，关注事实准确性、描述的信息量，以及 reward hacking。
- **Agent 评测**：检查任务要求、环境证据和评分规则是否对得上，尤其关注正确解法被误判、未完成任务却得分的问题。
